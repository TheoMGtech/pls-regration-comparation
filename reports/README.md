# Entrega consolidada

O relatório final será gerado a partir dos CSVs de cada `analyses/grupoN/outputs/`. O consolidado não executa notebooks nem modifica resultados individuais. Execute `python scripts/consolidate_results.py` somente depois de os cinco grupos preencherem seus outputs; ele gera MAE por base, vitórias e posição média em `reports/output/`, sem calcular média direta de MAE entre escalas. A entrega final deve conter HTML autocontido, PDF com o mesmo conteúdo, fonte do relatório, códigos, cinco bases e os CSVs consolidados.
