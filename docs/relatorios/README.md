# Relatórios da atividade

Esta área contém somente os artefatos editoriais destinados à entrega e à
apresentação. Cada `grupoN/` reúne o relatório local de uma base; o diretório
`consolidado/` reúne a narrativa comum das cinco bases.

Notebooks de modelagem, resultados intermediários e auditorias permanecem em
`analyses/grupoN/`. O relatório local não substitui o consolidado e não deve
ser usado para inferir comparações globais antes da conclusão das cinco bases.
