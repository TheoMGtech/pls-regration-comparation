# Grupo 5 — Base Ouro

Relatório local e estudo de caso da Base Ouro. A V1 congelada é a referência
oficial; a V2 aparece apenas como estudo complementar e não substitui o ranking
oficial.

Arquivos principais:

- `relatorio_ouro.ipynb`: fonte executável de composição leve;
- `relatorio_ouro.html`: versão autocontida e paginada;
- `relatorio_ouro.pdf`: versão estática equivalente;
- `apendice_tecnico.md`: evidências e ressalvas metodológicas;
- `referencias.md`: fontes institucionais, bibliotecas e trabalhos citados;
- `roteiro_apresentacao_ouro.md`: apoio para apresentar o estudo de caso.

A aula geral de PLS pertence ao relatório consolidado, não a este relatório
local. Auditorias e controles de processo estão em
`analyses/grupo5/auditorias/`.
